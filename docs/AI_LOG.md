# AI Usage Log

## Milestone 1 — Setup, Static Frontend, ERD

### Tools and tasks
- **ChatGPT:** Used for basic guidance with project structure, folder organization, and simple frontend planning.
- **GitHub Copilot:** Used for assistance with basic project setup and code suggestions.
- AI was used as a helper, while the project structure and implementation were reviewed and adjusted manually.

### Where the AI was wrong
1. AI suggestions sometimes needed adjustments to fit the existing project structure. This was noticed while reviewing the files, and the suggestions were adapted.
2. Some AI guidance was too general and did not fully reflect the milestone requirements. This was noticed by comparing the advice with the project specification, and the requirements were checked individually.
