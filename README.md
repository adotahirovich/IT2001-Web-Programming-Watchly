# Watchly — Watches & Jewelry Store

Watchly is a single-store web application for browsing watches and jewelry, registering and logging in, placing orders, and reviewing products. Administrators can manage products, users, roles, orders, and reviews.

## Technology
- HTML, CSS, JavaScript
- PHP
- MySQL
- JWT authentication
- OpenAPI

## Entities and Relationships
**Entities:** Roles, Users, Products, Orders, Reviews.

- Roles 1:N Users
- Users 1:N Orders
- Users 1:N Reviews
- Products 1:N Reviews

## Run Locally
1. Install XAMPP.
2. Start Apache in the XAMPP Control Panel.
3. Open the project through your local server.
